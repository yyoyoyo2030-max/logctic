# Logistic Pro 🚚

نظام إدارة لوجستيك احترافي متكامل

## المميزات

- ✅ إدارة التحويلات والشحنات
- ✅ إدارة السائقين والمركبات
- ✅ نظام المهام المتقدم
- ✅ تقارير شاملة
- ✅ إشعارات فورية
- ✅ واجهة عصرية بالعربية
- ✅ وضع ليلي

## المتطلبات

- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx

## التثبيت

1. ارفع الملفات على السيرفر
2. استورد `database.sql` في phpMyAdmin
3. حدّث إعدادات `config/config.php`
4. افتح الموقع في المتصفح

## تسجيل الدخول

- المستخدم: `admin`
- كلمة المرور: (من قاعدة البيانات)

⚠️ **غيّر كلمة المرور فوراً بعد أول تسجيل دخول!**
